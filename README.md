# Zomato Global Restaurant Analytics | Power BI

**Overview:** An interactive Power BI dashboard analyzing a global dataset of 9,500+ Zomato-listed restaurants to uncover geographical cuisine trends, cost-to-rating correlations, and delivery service insights.

**Tech Stack:** Power BI, Power Query, DAX, Excel

## Key Features Built
* **Data Modeling:** Established 1:1 and 1:* relationships with bidirectional cross-filtering across 4 core tables.
* **ETL & Power Query:** Appended 6 distinct continental datasets, split delimiter-separated cuisine strings into clean rows, and corrected spatial/geographical hierarchies.
* **Custom DAX Measures:** Engineered calculations for dynamic metrics including `Restaurant Count`, `Average Cost`, `Average Rating`, and conditional formatting.
* **UI/UX & Mobile:** Designed a synchronized two-page navigation system with dynamic slicers, synchronized gauge visuals, and a fully optimized vertical Mobile Layout.
